## Usage Examples

### Margin

```tsx
import { spacing, spacingSemantic } from '@your-org/polaris-design-library/tokens';

// Using specific spacing
const box = {
  margin: spacing['200'], // 16px
};

// Using semantic spacing
const section = {
  marginBottom: spacingSemantic.loose, // 24px
};
```

### Padding

```tsx
import { inset } from '@your-org/polaris-design-library/tokens';

const card = {
  padding: inset.lg, // 24px
};
```

### Flexbox Gap

```tsx
import { gap } from '@your-org/polaris-design-library/tokens';

const flexContainer = {
  display: 'flex',
  gap: gap.md, // 16px
};
```

### Grid Gap

```tsx
import { gap } from '@your-org/polaris-design-library/tokens';

const gridContainer = {
  display: 'grid',
  gap: gap.lg, // 24px
  gridTemplateColumns: 'repeat(3, 1fr)',
};
```

## Spacing Reference

| Token | Value | Pixels | Common Use |
|-------|-------|--------|------------|
| `none` | 0 | 0px | No spacing |
| `050` | 0.25rem | 4px | Extra tight spacing |
| `100` | 0.5rem | 8px | Tight spacing, icons |
| `200` | 1rem | 16px | Base spacing unit |
| `300` | 1.25rem | 20px | Medium spacing |
| `400` | 1.5rem | 24px | Large spacing |
| `600` | 2rem | 32px | Section spacing |
| `800` | 2.5rem | 40px | Large sections |
| `1000` | 3rem | 48px | Major sections |
| `1200` | 4rem | 64px | Page sections |
